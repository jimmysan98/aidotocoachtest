# AIDOTA Blueprint

## System Overview
AIDOTA is a local Windows real-time Dota 2 coaching and HUD companion built with Python (`./aidota/`) alongside a frozen legacy Rust companion workspace (`./aidota-core/`). The Python runtime orchestrates CLI/GUI launchers, Game State Integration (GSI) ingestion, strictly read-only offline baselines (`data/heroes.json`, `data/items.json`) paired with disk-backed OpenDota SWR synchronization (`meta_sync.py`), speech input with Dota slang normalization & Whisper biasing (Vosk / Groq Whisper), global hotkeys, OpenCV cursor recognition, 3-contour coaching architecture (0ms Contour 0 hero/map reflexes with disk audio prewarm, fast non-reasoning Contour 1 live voice with `SKIP` token & SSE/NDJSON sentence streaming, and async background Contour 2 `StrategyCard`), derived GSI signals (`context.py`), compact tri-state `EnemyState` modeling (`enemy_state.py`), pre/post deterministic item validation (`item_validator.py`), DeepSeek-first Tier 0/1/2 LLM routing with KV-stable `PromptAssembly`, anti-poisoning persistent memory, per-turn `ReplicaTrace` JSONL telemetry, and prioritized barge-in TTS playback (`tts.py`). `./aidota-core/` retains frozen legacy compatibility artifacts (`aidota_rust.dll`, loaded defensively via `aidota/rust_bridge.py`, and standalone Axum server `aidota-core`), while `./tools/` houses brand-asset, microphone-diagnostic, and CI test-runner utilities.

## Local Interface & Invariants
- `[main.py:build_parser]`, `[main.py:main]` — Root CLI entrypoint routing `--doctor`, `--online`, `--fetch-icons`, `--update-data`, `--install-gsi`, `--add-to-steam`, `--cli`, `--text`, `--ptt`/`--no-ptt`, `--ptt-key`, `--no-tts`, `--no-overlay`, and `--no-gsi`. Always reconfigures `stdout`/`stderr` to UTF-8, changes working directory to `PROJECT_ROOT`, enforces a Win32 single-instance mutex (`Global\AIDOTA_SingleInstance_Mutex`) unless `--cli`/`--text`, and launches either `aidota.gui_app.run_gui_app` or console `aidota.app.Assistant`.
- `[build_exe.py:app_version]`, `[build_exe.py:find_iscc]`, `[build_exe.py:copy_dist_extras]`, `[build_exe.py:build_installer]`, `[build_exe.py:main]` — PyInstaller (`AIDOTA.spec`, excluding `sqlite3`) + Inno Setup 6 (`installer.iss`) packager. Bundles `EXTRA_DIRS` (`hero_icons`, `assets`), strictly allowlisted read-only `ALLOWED_DATA_FILES` (`data/heroes.json`, `data/items.json`), `EXTRA_FILES` (`default_preset.json`, `config.example.json`, `LICENSE`, `CHANGELOG.md`, `README.md`, `installer_notes.txt`, `THIRD_PARTY_NOTICES.md`), and optional `vosk-model-small-ru-0.22/` into `dist/AIDOTA`, while explicitly deleting `FORBIDDEN_IN_DIST` (`config.json`, `installer.iss`, `AIDOTA.spec`, `build_exe.py`), `FORBIDDEN_IN_DIST_DATA` (`coach_memory.json`, `player_profile.json`), and leftover cache/log files.
- `[clean_project.py:clean_caches]`, `[clean_project.py:clean_build_artifacts]`, `[clean_project.py:optimize_hero_icons]`, `[clean_project.py:main]` — Workspace cleaner and asset optimizer removing `__pycache__`, `.pytest_cache`, `.cache`, `build`, `*.pyc`/`*.pyo`, and `logs/*.log` (while skipping `.venv/`, `.git/`, and `dist/` by default), and quantizing `hero_icons/*.png` to 256-color palette PNGs via Pillow.

## Subdirectories & System Boundaries
- `aidota`: [./aidota/EGM.md](./aidota/EGM.md) - Canonical Python coaching runtime: writable/read-only path resolver (`paths.py`), GSI receiver (`gsi.py`), OpenDota API client (`dota_api.py`) & SWR cache sync (`meta_sync.py`), hero meta/threat DB (`meta_db.py`), item advice (`live_advice.py`), canonical map timers (`map_timers.py`), tri-state enemy tracker (`enemy_state.py`), RU-slang item registry & Zero-LLM validator (`item_validator.py`), DeepSeek-first router (`llm_router.py`), KV-stable `PromptAssembly` (`prompt_assembly.py`), LLM prompt/sanitization (`coach_brain.py`), coach orchestration (`coach.py`), long-term memory (`coach_memory.py`), secret redaction (`security.py`), JSONL telemetry (`telemetry.py`), inactive-by-default Rust FFI bridge (`rust_bridge.py`), WebView bridge (`web_app.py`), modular skills ([./aidota/skills/EGM.md](./aidota/skills/EGM.md)), and SPA UI ([./aidota/web/EGM.md](./aidota/web/EGM.md)).
- `aidota-core`: [./aidota-core/EGM.md](./aidota-core/EGM.md) - Frozen legacy Rust `v1.3.0` engine crate (`aidota_rust` cdylib/rlib + `aidota-core` binary) spanning [./aidota-core/src/EGM.md](./aidota-core/src/EGM.md) (`state.rs`, `lib.rs`, `main.rs`) and domain submodules `advice`, `gsi`, `timers`, and `web`.
- `tools`: [./tools/EGM.md](./tools/EGM.md) - Standalone developer/CI scripts (`generate_logo.py`, `mic_test.py`, `run_tests.py`).

## Global Invariants
- **Python + Read-Only `data/` Single Source of Truth (`aidota-core/` Frozen)**: Python modules together with strictly read-only bundled `data/heroes.json` and `data/items.json` (`BUNDLED_DATA_ALLOWLIST`) form the sole authoritative runtime logic. All tactical rules—canonical map timers (`aidota/map_timers.py`, delegated from `aidota/skills/macro_timer.py` and `aidota/context.py:MidTimersTracker`), counter-item/threat tables (`aidota/meta_db.py`, `aidota/live_advice.py`), tri-state `EnemyState` (`confirmed` | `inferred` | `unknown` in `aidota/enemy_state.py`), and bidirectional item validation (`aidota/item_validator.py`)—live exclusively in Python. Tactical duplicates in `aidota-core/` (`src/timers/macro_timer.rs`, `src/advice/counter_items.rs`) are officially frozen for legacy compatibility/build stability only and must not evolve independently.
- **Fail-Safe Native FFI Loading**: `aidota/rust_bridge.py` suppresses Windows Smart App Control / Bad Image modal dialogs via `SetErrorMode`/`SetThreadErrorMode` around `ctypes.CDLL`, caches a single load attempt per process, and falls back to pure Python when `aidota_rust.dll` is absent, blocked, or disabled via `AIDOTA_DISABLE_RUST`.
- **Default Configuration Parity**: `default_preset.json` and `config.example.json` remain synchronized schema baselines; `config.json` contains user-local state and must never be shipped in `dist/` or committed.
- **No Unmocked Network in Tests**: Python unit tests mock HTTP/LLM/audio I/O offline; running Python GSI and legacy Rust servers binds loopback `127.0.0.1` (`:3000` GSI, `:8080` Rust web UI).

## Global Side Effects
- `data/heroes.json` and `data/items.json` in the install/workspace `data/` directory are strictly **read-only** offline baselines and are never mutated at runtime.
- Runtime writable state routes via `aidota/paths.py` to `%LOCALAPPDATA%\AIDOTA\` in frozen builds (`AIDOTA.exe` or `AIDOTA_DATA_DIR` override) and to local workspace directories in dev mode: `config.json`, OpenDota SWR cache & `sync_state.json` (`.cache/meta/`), `logs/aidota.log`, redacted turn telemetry `logs/metrics.jsonl`, long-term memory `coach_memory.json`, player profile `player_profile.json` (`data/` under `%LOCALAPPDATA%\AIDOTA\` when frozen), and icon/audio caches (`hero_icons/`, `.cache/`). Packaging writes `dist/` / `AIDOTA_Setup.exe`, and Steam integration edits `gamestate_integration_aidota.cfg`, `localconfig.vdf`, `shortcuts.vdf`, and the Windows `HKCU\...\Run` registry key.
- Opens local loopback HTTP/WebSocket ports (`127.0.0.1:3000`, `127.0.0.1:8080`), desktop GUI loops (`pywebview` / CustomTkinter / Tkinter overlay / Win32 tray), Win32 low-level keyboard/mouse hooks, audio capture/playback streams, and outbound HTTPS connections to OpenDota, Steam CDN, Edge-TTS, Groq, Vosk mirrors, and configured LLM providers.

## System Verification
- Python suite (`pytest`): `.venv\Scripts\python.exe -m pytest`
- Lint (`ruff` on CI target modules and tests, matching `.github/workflows/ci.yml`): `.venv\Scripts\python.exe -m ruff check ...`
- Strict typecheck (`mypy` on configured modules in `pyproject.toml`): `.venv\Scripts\python.exe -m mypy`
- Bytecode compile check: `.venv\Scripts\python.exe -m compileall -q aidota tests main.py build_exe.py`
- Python suite (CI unittest runner): `.venv\Scripts\python.exe tools/run_tests.py`
- Python suite (direct unittest): `.venv\Scripts\python.exe -m unittest discover -s tests`
- Packaging smoke build (PyInstaller `AIDOTA.spec`): `.venv\Scripts\python.exe build_exe.py --pyinstaller-only`
- Rust crate tests (from `aidota-core/`, frozen legacy): `cargo test` *(note: currently blocked on hosts with Windows Application Control Policy `os error 4551` when executing Cargo build scripts)*
