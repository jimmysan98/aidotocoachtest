# aidota

## Overview
Core Python package implementing the AIDOTA real-time Dota 2 voice and HUD coaching application. It connects Dota 2 Game State Integration (GSI), OpenDota snapshots/match history and disk-backed SWR patch-meta synchronization (`<= 1 req/s`), unified read-only/writable `%LOCALAPPDATA%\AIDOTA` path resolution, local Vosk / Groq Whisper speech recognition, Win32 global hotkeys, OpenCV cursor hero vision, an optional (presently inactive) Rust FFI accelerator, deterministic tactical rules and hero meta databases, DeepSeek-first Tier 0/1/2 LLM routing with `generation_id` preemption, KV-stable `PromptAssembly`, secret redaction, JSONL turn telemetry, persistent memory, prioritized Edge/Piper/SAPI/RVC text-to-speech, and desktop UI surfaces (pywebview SPA, CustomTkinter dashboard, Tk transparent overlay, and Windows system tray).

## Invariants
- `[__init__.py]` & `[coach_brain.py]` — package root avoids heavy imports (`vosk`, `cv2`, `sounddevice`) for `--doctor` and unit tests; `coach_brain` never imports `aidota.coach` at module level to avoid circular imports; neither `aidota/` nor tests import `sqlite3` (excluded in `AIDOTA.spec`).
- `[paths.py]` & `[config.py:load_config]` / `[config.py:save_config]` / `[context.py]` / `[coach_memory.py]` — bundled `data/heroes.json` and `data/items.json` (`BUNDLED_DATA_ALLOWLIST`) remain strictly read-only offline baselines; writable `config.json`, SWR OpenDota cache, `429` backoff state, `logs/aidota.log`, `metrics.jsonl`, `coach_memory.json`, and `player_profile.json` route to `%LOCALAPPDATA%\AIDOTA\` in frozen builds (or project / `.cache/` in dev); JSON writes are atomic (`tmp` + `fsync` + `os.replace`) and corrupt JSON falls back cleanly without crashing.
- `[config.py:_validate_profile]` — `default_position` must be a non-bool integer in `1..5` (else raises `ConfigError`); `account_id <= 0` or invalid coerces to `None`; `save_config` keeps in-memory `api_key` unmutated, registers secrets via `register_config_secrets`, and obfuscates non-empty `api_key` on disk with `"enc:"`.
- `[meta_sync.py]` & `[dota_api.py]` — hot-path `item_popularity`/`hero_matchups` with `auto_swr=True` perform zero synchronous HTTP calls; bulk sync uses 3 endpoints (`/heroStats`, `/constants/items`, `/constants/patch`, 24–72h TTL) and lazy SWR caches `/itemPopularity` + `/matchups` strictly for <= 10 unique active match heroes under `<= 1 req/s` (`RateLimiter`) and persisted `429 Retry-After` backoff; background `aidota-meta-sync` worker starts even when `snapshot_time is None` and joins cleanly on `close()`; `cache_version` invalidates `Coach.item_costs`, `AidotaWebApi` caches, and `meta_db` `@lru_cache`.
- `[logging_setup.py]` / `[security.py]` — `SecretRedactingFilter` and `RedactingFormatter` redact registered secrets, `Bearer` tokens, key query params, and `sk-*`/`enc:*` tokens across `logs/aidota.log`, console output, and `TelemetrySink` (`logs/metrics.jsonl`).
- `[gsi.py:GsiServer]` / `[app.py:Assistant.is_gsi_connected]` / `[web_app.py:AidotaWebApi.get_state]` — HTTP `POST` rejects bodies `<= 0` or `> MAX_BODY` (4 MiB) with HTTP 400 and validates `auth.token` in constant time via `hmac.compare_digest` (HTTP 401 on mismatch); GSI staleness threshold is `45.0` seconds.
- `[app.py:Assistant]` — in open-mic mode, commands without the active trainer wake word (`ASTRA_REGEX` / `JARVIS_REGEX`) are ignored; utterances addressing the inactive trainer are discarded; `_say` speaks via async TTS (`wait=False`) with generation tracking and `_skills_monitor` isolates sub-step exceptions.
- `[coach.py:Coach]` & `[llm_router.py]` & `[prompt_assembly.py]` — `Coach._build_turn_assembly` + `PromptAssembly` keeps `messages[0]["content"]` (static rules + sorted match roster) byte-identical across ALL `_ask_llm` callers and GSI ticks, places compact match snapshot (`stage`, 30–45s objectives window, slots, threats) and turn instructions strictly inside `dynamic_suffix`, strips `<think>` blocks, and trims history in `epoch_size=4` chunks; combat/voice (`voice=True`) and urgent picks (`kind="pick"`) force Tier 1 (`deepseek-chat` with `3.0s`/`6.0s` deadlines and `COACH_TOOLS` stripped); strategic `kind="draft"`/`"game_analysis"`/`"match"` and deep tavern chat use Tier 2 (`deepseek-reasoner`, `api_max_tokens >= 4096`, `temperature` & `tools` stripped, `reasoning_content` logged debug-only) with `deepseek-chat` fallback; `401/403`/`402` errors and keyed configs never fail over to Pollinations; `_COUNTER_HINTS`/`_ENEMY_ITEM_HINTS` duplicate tables removed in favor of `meta_db`/`live_advice`.
- `[coach_brain.py:build_brief]` / `[coach_brain.py:sanitize_answer]` — offline payloads return `available=False`, `stage="offline"`; `render_brief` defaults to `max_chars=1100`; `render_prompt_assembly` accepts `match_snapshot` in Segment 2; `sanitize_answer` strips refusals, emoji, markdown, and filler prefixes, caps sentences/characters by `detail_mode`/`skill_level`/`kind`, and guarantees terminal punctuation.
- `[map_timers.py]` & `[context.py]` — `aidota-core/` tactical duplicates are frozen; `CanonicalMapTimers` is the SSOT for bounty/water/power runes, wisdom, lotuses, catapults, day/night, stacks/pulls, Tormentor, edge-triggered neutral tiers (`7/15/25/35/60`, Turbo `0.5x`), and `matchid`-scoped auto-reset; `detect_enemy_mid_level` filters by mid lane metadata/role instead of sidelaner `max(level)`; `exp_pct` normalization distinguishes `0..1` vs `0..100`; `AutonomousCoachAgent.process_tick` enforces `is_autonomy_off()` BEFORE timers and Aegis/Roshan and coordinates via shared `MacroTimerSkill` `CanonicalMapTimers` core to prevent same-tick double-firing.
- `[live_advice.py:build_item_advice]` & `[meta_db.py:META_HEROES_DB]` — `live_advice` and `meta_db` own all canonical enemy notes/threat summaries (`_ENEMY_THREAT_HINTS` and `_HERO_THREAT_ALIASES` removed from `context.py`); `build_item_advice` deduplicates across 4 ordered stages, blocks `_HARD_CARRY_ITEMS` for positions 4–5 outside counter/fallback sources, and suppresses base components of owned `_UPGRADE_EQUIVALENTS`.
- `[enemy_state.py]` & `[item_validator.py]` — tri-state `EnemyObservationState` (`confirmed` | `inferred` | `unknown`) strictly enforces epistemic markers (`inferred`/`unknown` never presented as confirmed fact, fog of war clearly distinguished); `EnemyStateTracker` synchronizes enemy picks, spectator/lobby `allplayers`, and voice/WebUI player confirmations across GSI ticks; `item_validator` provides bidirectional Russian slang <-> English slug/canonical registry with aliases, accounts for `stash*`, backpack, consumed Scepter/Shard/Moon Shard buffs and `_UPGRADE_EQUIVALENTS`, detects 8 draft team gaps (`control`, `push`, `frontline`, `save`, `dispel`, `antiheal`, `break`, `true_strike`), and deterministically replaces invalid/removed/already-owned items via Tier 0 with zero LLM retries.
- `[commands.py:parse_command]` & `[heroes.py:HeroCatalog]` — `check_wake_word` rejects utterances directed at the opposite trainer; `_KEYWORDS` tuple order controls intent precedence; `HeroCatalog` ranks alias matches before substring (`>= 0.97`) and rapidfuzz/difflib fuzzy matches.
- `[tts.py:HumanTTSManager]` — `PriorityQueue` orders items by `(SpeechPriority, seq)`; `CRITICAL` triggers `barge_in()`, bumping `generation_id` and draining stale queued items; expired items (`age > ttl`) and pre-empted generations are re-checked immediately before playback; synthesis cascades cache -> Edge-TTS (`10.0s`) -> Piper (`30.0s`, writing to a temp WAV file instead of `-` stdout to prevent Windows CRT `0x0A`->`0x0D 0x0A` static corruption) -> SAPI -> pyttsx3; `_is_corrupted_static_waveform` purges/blocks corrupted white-noise waveforms from cache and playback.
- `[audio.py:VoiceInput]` & `[hotkeys.py:HotkeyListener]` — `VoiceInput` serializes recognizer calls with `_recognizer_lock` and switches to text fallback on stream/model errors; `HotkeyListener` pumps Win32 `WH_KEYBOARD_LL`/`WH_MOUSE_LL` and `RegisterHotKey` on a single `aidota-hotkey` thread and keeps ctypes callback references alive.
- `[gui_app.py:AidotaApp]` / `[overlay.py:Overlay]` / `[settings_gui.py:SettingsDialog]` / `[web_app.py:WebGuiController]` — Tk/CTk UI mutations run exclusively on the Tk main thread (`after(0, ...)`); `WebGuiController.start_assistant` forces `cfg.overlay.enabled = False`; `AidotaWebApi.get_state()` exposes Python SSOT `macro_timers` alongside `rust_active=False` and `operating_mode`, `record_roshan()` updates canonical `CooldownTrackerSkill`, `get_settings()` masks `llm_api_key`, `save_settings()` persists `ollama` cleanly, `run_doctor()` maps `Check.detail`/`hint`, and `send_chat()` calls `tts.speak(..., wait=False, priority=SpeechPriority.LLM_COACH)`.
- `[rust_bridge.py]` — DLL loading runs once per process (`_INIT_ATTEMPTED`), can be disabled via `AIDOTA_DISABLE_RUST`, masks Win32 error dialogs via `SetErrorMode`/`SetThreadErrorMode` during `CDLL`, and frees native strings with `aidota_free_string`.
- `[doctor.py:run_doctor]` — returns `1` only when any check has status `"FAIL"` (`OK`/`WARN` return `0`); `download_vosk_model` skips download when `am/final.mdl` already exists; HTTP error strings are redacted via `redact_secrets`.

## Side Effects
- **Disk I/O**: reads read-only bundled `data/heroes.json`, `data/items.json`; reads/writes `%LOCALAPPDATA%\AIDOTA\` (frozen) or project `.cache/`/`data/`/`logs/` (dev) for `config.json` (`config.py`), SWR meta cache files & `sync_state.json` (`meta_sync.py`), `player_profile.json` (`context.py`), `coach_memory.json` (`coach_memory.py`), `logs/aidota.log` (`logging_setup.py`), `logs/metrics.jsonl` (`telemetry.py`), cached WAVs and Piper binaries (`tts.py`), `hero_icons/*.png` and `.cache/item_icons/*.png` (`icons.py`, `vision.py`, `web_app.py`), Vosk models (`doctor.py`, `audio.py`), and Steam `gamestate_integration_aidota.cfg`, `localconfig.vdf`, and `shortcuts.vdf` (`dota_install.py`).
- **Network I/O**: binds HTTP GSI listener (`gsi.py`), sends HTTPS requests to OpenDota API (`dota_api.py`, `meta_sync.py` under `<= 1 req/s`), Steam CDN (`icons.py`, `web_app.py`), Edge-TTS (`tts.py`), Groq Whisper (`audio.py`), Alphacephei Vosk downloads (`doctor.py`), and configured DeepSeek / OpenAI-compatible / Ollama / Pollinations endpoints (`coach.py`, `doctor.py`, `settings_gui.py`, `web_app.py`).
